# Cervejaria Artesanal - Vitrine Online

## Descrição e Objetivo
Projeto de uma vitrine virtual para venda de cervejas artesanais. O objetivo inicial é estabelecer uma base sólida de HTML5 utilizando semântica estrita, garantindo máxima acessibilidade (diretrizes WCAG 2.2) e otimização para motores de busca (SEO técnico com Schema.org).

## Estrutura do Projeto
\`\`\`
cerveja-artesanal-vitrine/
├── index.html        # Estrutura base e semântica
├── css/
│   └── style.css     # Estilos globais e componentes (BEM)
├── js/
│   └── main.js       # Interatividade e regras de negócio
├── assets/
│   └── img/          # Imagens otimizadas (WebP, SVG)
├── README.md         # Documentação
├── .gitignore        # Arquivos ignorados pelo Git
└── LICENSE           # Licença MIT
\`\`\`

## Como Rodar Localmente
1. Clone este repositório:
   \`git clone https://github.com/seu-usuario/cerveja-artesanal-vitrine.git\`
2. Navegue até a pasta:
   \`cd cerveja-artesanal-vitrine\`
3. Abra o arquivo \`index.html\` no seu navegador ou utilize extensões como o *Live Server* no VS Code para auto-reload.
